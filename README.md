# Beecrowd 1041 - Coordenadas de um Ponto



## Descrição



Este programa resolve o problema 1041 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém dois valores de ponto flutuante que representam as coordenadas X e Y de um ponto.



## Saída



O programa apresenta o quadrante em que o ponto se encontra, ou informa se está sobre um dos eixos ou na origem.
